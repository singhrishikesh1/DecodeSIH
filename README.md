## ✨ Key Features

- 🛰️ **Live Telemetry & GIS Command** — Real-time drone fleet tracking across Pune GIS zones (*Viman Nagar, Kharadi, Wagholi*) with Google Maps integration.
- 🎮 **3D Flight Simulation** — Interactive 3D Flying Drone Canvas for flight path visualization.
- 🧠 **AI Vision & Analytics Engine** — Defect detection, volumetric 3D analysis, and cost/risk evaluation modules.
- 🛠️ **Fleet Maintenance Hub** — Comprehensive servicing lifecycle tracking and diagnostic alerts.
- 📄 **1-Click Audit Reports** — Instant PDF generation for structural inspection logs and compliance audits.
